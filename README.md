# Knigi — каталог книг с поиском

Веб-приложение для поиска книг и аудиокниг, чтения описаний, выставления оценок, написания отзывов и ведения личной библиотеки (аналог сервиса MyBook).

## Целевая аудитория и решаемая задача
Приложение предназначено для читателей и слушателей аудиокниг. Оно решает задачу быстрого поиска произведений по названию, автору и жанрам, сохранения выбранных книг на личную полку и обмена отзывами.

## Основные возможности
* Каталог книг с фильтрацией по плашке жанров и категорий
* Поиск произведений по названию и автору
* Детальная карточка книги с оценками и отзывами пользователей
* Встроенный аудиоплеер для книг с аудиоверсией
* Регистрация, вход в аккаунт и личная библиотека («Читаю», «Хочу прочитать», «Прочитано»)

## Переменные окружения
Перед запуском скопируйте `.env.example` в `.env`:
* `DATABASE_URL` — путь к файлу базы данных SQLite (`file:./dev.db`)
* `AUTH_SECRET` — секретный ключ для подписи сессий

## Инструкция по локальному запуску

1. Склонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com/WHITESHARK2307/book-catalog-with-search.git
   cd book-catalog-with-search
   ```

2. Скопируйте файл переменных окружения:
   ```bash
   cp .env.example .env
   ```
   *(В Windows PowerShell можно использовать: `copy .env.example .env`)*

3. Установите зависимости:
   ```bash
   npm install
   ```

4. Сгенерируйте клиент Prisma:
   ```bash
   npx prisma generate
   ```

5. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

После запуска откройте (http://localhost:3000) в браузере.
